# Digital Visual Media Reference

Digital visual work is temporal, responsive, and rendered through a device. Evaluate not only the screen image but reading distance, viewport, loading, motion, sound, input, accessibility, and what remains when motion or sound is unavailable.

## Visual sequence map

```text
entry → orientation → visual event → pause/feedback → next reading
             ↘ interruption / loading / reduced-motion state ↗
```

## Prototype levels

| Level | Learn |
|---|---|
| storyboard | sequence and framing |
| motion mockup | timing, rhythm, transition |
| clickable visual prototype | navigation and state of the visual composition |
| coded prototype | responsive behavior, rendering, performance |

## Responsible practice

Consider captions, contrast, reduced motion, sound alternatives, text scaling, data provenance, privacy when personal images are used, and the environmental cost of heavy media. A static mockup cannot prove a moving or responsive visual experience.
