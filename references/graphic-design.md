# Graphic Design Reference

## Working principles

Graphic design organizes attention, interpretation, and action through relationships among content, form, sequence, and context. Evaluate hierarchy, contrast, rhythm, alignment, scale, legibility, material, reproduction, and audience—not surface style alone.

## Useful questions

- What must be noticed, understood, remembered, or done?
- What is the relationship between text and image: evidence, contradiction, caption, interface, or atmosphere?
- What does the grid reveal or conceal?
- Which formal rule can generate a family of outputs?
- What changes across scale, medium, language, and access condition?

## Process reference

```text
content audit → audience/context → hierarchy → formal hypothesis
→ small tests → comparison → system rules → production proof
```

## Exercise bank

- Make the same content communicate three different positions.
- Remove the obvious visual metaphor and rebuild from observed behavior.
- Produce a second and edge-case output using the same system.
- Test the work at intended reading distance and in its actual medium.

## Critique cue

Describe how the artifact makes meaning. “Good composition” is not enough; name the hierarchy, pacing, material choice, and audience consequence.
