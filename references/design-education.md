# Visual Design Education Reference

## Portfolio review lenses

Use these as emphasis areas, not guaranteed admissions formulas. Verify current requirements from each institution's official source.

| Program context | Emphasize |
|---|---|
| RCA | conceptual depth, criticality, social context, narrative, reflection |
| UAL/CSM | visual authorship, experimentation, storytelling, material exploration |
| SVA | formal development, visual communication, craft, personal voice |
| Parsons | concept, research, cultural context, visual system, articulation |
| general visual design | question, evidence, position, translation, making, iteration |

## Portfolio evidence chain

```text
context → question → method → evidence → insight → position
→ visual principle → experiment → selection → system → outcome → reflection
```

## Reference-source roles

- Official school/archive material: context and stated expectations.
- Year-bounded graduate archives: historical comparison; record the year and source.
- Behance: project structure and process presentation.
- Pinterest: visual discovery only; trace the original source.
- Creative Review: professional discourse and published cases.
- Core77: design precedent and practice context.

For each source record author, title, date, URL, what it demonstrates, what is transferable, and what must not be copied. Do not infer a program's expectations from a visual stereotype.

## Applicant self-audit

1. What can a reviewer understand in one minute?
2. What can they verify in five minutes?
3. Where is the student's judgment visible?
4. Which decision changed after evidence?
5. What limitation or next question is acknowledged?
