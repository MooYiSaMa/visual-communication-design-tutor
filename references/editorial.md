# Editorial and Publishing Reference

## Editorial thinking

An editorial project creates a sequence of attention. It has an argument, a reader, a pace, an entry point, a turn, and an ending—not just a collection of pages.

## Structure questions

- What is the reader expected to know before each section?
- Where does evidence become interpretation?
- Which page is the narrative hinge?
- What can be shown rather than explained?
- How do captions, indexes, footnotes, and metadata produce trust?
- What changes between print, screen, installation, and oral presentation?

## Page architecture

```text
orientation → evidence → complication → position → experiment
→ system → outcome → reflection
```

Use pacing deliberately: dense analysis, visual pause, comparison, and return. Maintain credits, source notes, accessibility, translation, and reading order.

## Editorial experiment

Make three sequences from the same material: chronological, argumentative, and associative. Compare what each makes visible and what it hides.
