# Typography Reference

## Typography as behavior

Type can signal voice, authority, intimacy, uncertainty, speed, hierarchy, or interruption. Start with reading conditions and language before choosing a typeface.

## System checklist

- role hierarchy: title, label, body, metadata, instruction, annotation;
- scale, measure, leading, tracking, and paragraph rhythm;
- language/script coverage and fallback behavior;
- contrast, legibility, responsive sizing, and reading distance;
- variable states: emphasis, error, time, voice, interaction, or uncertainty;
- licensing, production, rendering, and print/screen constraints.

## Experiments

Test one meaning through hierarchy, spacing, weight, sequence, redaction, and variable behavior. Keep the content constant where comparison matters. Record what the reader actually notices or misunderstands.

## Anti-style rule

Do not select type because it looks “RCA,” “editorial,” “futuristic,” or “premium.” Select and modify a typographic system because it supports the position and audience experience.
