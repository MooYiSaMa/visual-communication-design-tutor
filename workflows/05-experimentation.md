# 05 — Experimentation

## Purpose

Use making to learn. Each experiment should isolate a question and produce comparable evidence.

## Hypothesis format

> If I use ___ to express/test ___, then the audience/material/system will ___, because ___. I will judge it by ___

## Experiment set

Create 3–5 deliberately different tests, varying one meaningful dimension at a time when possible:

| ID | Hypothesis | Variable | Prototype | Evidence to collect | Stop/keep signal |
|---|---|---|---|---|---|
| X01 | what might happen | type/image/time/material | small artifact | behavior/reading/quality | criterion |

Possible tests include sequence versus simultaneity, presence versus absence, audience reconstruction, material degradation, typographic rhythm, image source transformation, navigation within a visual narrative, or responsive visual behavior.

## Experiment rules

- Time-box each test; avoid polishing before learning.
- Keep the same content where comparison matters.
- Name what is intentionally held constant.
- Include at least one test that could disprove the preferred direction.
- For AI-generated imagery, record prompt intent, model contribution, selection/editing, provenance, and what the image tests. Do not present generated images as primary research or personal photography.
- For user testing, define participant, task, context, observation, and consent before collecting feedback.

## Compare, do not vote

Use a criteria matrix tied to the position:

| Criterion | X01 | X02 | X03 | Evidence |
|---|---:|---:|---:|---|
| expresses the intended tension |  |  |  | why |
| produces the intended audience action |  |  |  | what happened |
| has authorship |  |  |  | what is specific |
| can scale into a system |  |  |  | repeatability |
| ethical/accessible/feasible |  |  |  | limitation |

Scores support reasoning; they do not replace it.

## Iteration record

Write: “We learned ___, so we changed ___; this improved/complicated ___, but leaves ___ unresolved.” Preserve failed experiments when they reveal a meaningful decision.

## Experiment gate

Advance only when the selected direction has a supported learning, a known limitation, and a clear next test or development rule.
