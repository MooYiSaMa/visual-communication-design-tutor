# 04 — Visual Translation

## Purpose

Derive a visual language from a concept without reducing the topic to a fashionable effect.

## Procedure

1. State the concept and intended audience experience.
2. Identify the behavior, tension, or relation that the audience should encounter.
3. Derive a visual principle.
4. Propose 3–5 formal devices across type, image, composition, material, motion, and medium.
5. Make small tests before choosing a style.
6. Compare how each device changes reading and meaning.

## Formal hypothesis

> Because research/position showed ___, I will use ___ to make the audience ___; I will test this through ___ and judge it by ___

## Anti-metaphor rule

Do not map “loneliness” directly to empty space, “digital” to glitch, or “memory” to blur. Ask which observed behavior requires the device. Ban the first obvious device for one experiment and compare it with the control.

## Translation matrix

| Dimension | Decision question | Test |
|---|---|---|
| Typography | How should reading, voice, hierarchy, or interruption behave? | same text, three systems |
| Image | What is shown, withheld, transformed, or credited? | source/crop/sequence comparison |
| Color | Does color carry meaning, state, culture, or atmosphere? | semantic versus decorative use |
| Composition | What controls attention, scale, density, and time? | alternate grids/sequences |
| Material | What does process, surface, or decay contribute? | physical/digital material tests |
| Motion | What changes and why? | trigger, duration, pause, reduced motion |
| Content | What needs caption, context, translation, or evidence? | reading and misreading test |
| Medium | What can this medium uniquely enable or constrain? | medium-specific prototype |
