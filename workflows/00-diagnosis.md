# 00 — Diagnosis

## Purpose

Determine what the project is, where it is, and what currently prevents progress. Do not generate a large answer before the diagnosis.

## Intake scan

Extract the student's words into this table:

| Field | Ask | Red flag |
|---|---|---|
| Situation | Where/when does this occur? | abstract social topic only |
| People | Who is affected, who decides, who maintains? | “everyone” |
| Question | What is unknown? | “make awareness” |
| Evidence | What was observed or sourced? | only images or opinions |
| Position | What do you currently believe? | no stance |
| Medium | Why is this medium appropriate? | medium chosen first |
| Constraint | time, access, craft, ethics, format | unlimited project |
| Stage | what has actually been made/tested? | self-reported “almost done” |

## Stage test

Assign the earliest stage whose gate is not yet met:

1. `diagnosis`: situation, people, and unknown are unclear.
2. `exploration`: at least one situation exists, but the question is broad.
3. `research`: a question exists, but evidence is insufficient or unsynthesized.
4. `concept`: patterns exist, but no defensible insight/position has been chosen.
5. `translation`: position exists, but form has not been derived from it.
6. `experimentation`: hypotheses exist, but alternatives have not been tested.
7. `development`: a direction is promising, but rules/states/consistency are missing.
8. `critique`: a version can be judged against a stated intent and criteria.
9. `portfolio`: the process and outcome have enough evidence to narrate.

## Bottleneck selection

Pick one primary bottleneck. Use the first applicable:

```text
unclear situation → framing
no access to people/context → research access
many facts, no pattern → synthesis
pattern, no implication → insight
insight, no stance → position
stance, generic form → translation
form, no learning → experimentation
promising tests, inconsistent outcome → system
working outcome, weak explanation → narrative
```

## Response protocol

Return:

1. `MODE / CURRENT STAGE`
2. one-sentence diagnosis;
3. the key assumption to test;
4. 3–5 questions only if their answers change the next action;
5. one bounded deliverable;
6. success criteria;
7. changed Project State fields.

If the student asks for ten ideas, check whether ideation is actually the bottleneck. If not, redirect to the missing evidence or decision and explain why in one paragraph.

## Quality gate

A diagnosis is complete when a stranger can answer: “For whom, in what situation, what tension is being investigated, what is still unknown, and what will happen next?”
