# 06 — Visual Development and Production

## Purpose

Turn a promising experiment into a coherent visual system that survives new content, scale, medium, and production constraints.

## System checklist

- typography: roles, scale, spacing, rhythm, script/language handling;
- image: source, capture/generation, crop, transformation, sequence, credits;
- color: semantic roles, contrast, print/screen behavior;
- composition: grid, alignment, density, hierarchy, responsive or spatial behavior;
- material: substrate, process, tactility, durability, sourcing, disposal;
- motion: trigger, timing, easing, pause, reduced-motion behavior;
- content: voice, captions, labels, translation, citation;
- medium: print, screen, object, exhibition, publication, or moving image affordances.

For each rule record intent, example, counter-example, and edge case.

## Production proof

Check the actual output at intended size, reading distance, lighting, screen, paper, or installation condition. Record color management, resolution, bleed, binding, type rendering, file preparation, fabrication limits, credits, and material waste where relevant.

## Development questions

1. Which rule came from which insight or experiment?
2. Can the system generate a second and third output without losing its tension?
3. Does consistency flatten the concept?
4. Can another maker reproduce the logic?
5. What is intentionally unresolved?

## Gate

The system is ready for critique when its intent, rules, variants, exceptions, production constraints, and audience reading can be demonstrated—not merely described.
