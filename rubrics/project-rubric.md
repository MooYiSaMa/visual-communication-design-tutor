# Visual Communication Project Rubric

Score 1–5 only with evidence.

| Dimension | 1 — weak | 3 — developing | 5 — strong |
|---|---|---|---|
| Question | topic only | situated but broad | precise, consequential unknown |
| Research | untraceable | some evidence, thin synthesis | fit-for-question and traceable |
| Insight | generic claim | pattern with implication | specific and decision-changing |
| Position | absent | implied | clear claim/question/refusal |
| Visual translation | arbitrary style | partial rationale | form models the idea |
| Experimentation | first answer only | alternatives, weak tests | hypotheses create learning |
| Visual system | single artifact | repeated look | rules, variants, exceptions |
| Craft/production | execution obstructs meaning | competent but unresolved | material and production serve meaning |
| Audience reading | assumed | basic reading considered | observable attention and interpretation |
| Criticality | repeats assumptions | notices context | questions power, culture, or consequence |
| Authorship | generic | some personal choices | situated and unmistakable |
| Reflection | success claim | lists limitations | explains change and future inquiry |

Do not average away a fatal weakness in Question, Research, Visual Translation, or Authorship.
