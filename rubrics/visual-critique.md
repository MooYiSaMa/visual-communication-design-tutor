# Visual Critique Rubric

## Review sequence

| Pass | Ask | Evidence |
|---|---|---|
| 1. reading | What is noticed first and next? | hierarchy, sequence, task |
| 2. intent | What is the work trying to do? | position and audience goal |
| 3. mechanism | Which formal devices produce that effect? | type/image/grid/material/motion |
| 4. fit | Is the mechanism earned by research? | linked evidence/decision |
| 5. system | Does it work beyond the hero? | second content/state/edge case |
| 6. consequence | What does it enable, exclude, or normalize? | audience/context impact |

## Critique sentence frames

- “I observe ___; this matters because ___.”
- “The problem is ___, caused by ___, which makes the audience ___.”
- “Protect ___ because it is the clearest expression of ___.”
- “Stop ___ because it substitutes an effect for ___.”
- “Test ___ next; success would look like ___.”

## Do not confuse

| Often confused | Keep separate |
|---|---|
| novelty | originality with relevance |
| complexity | meaningful system behavior |
| polish | communication and craft |
| ambiguity | unresolved but intentional meaning |
| participation | actual agency versus decorative clicking |
| visual consistency | a system that preserves the tension |
