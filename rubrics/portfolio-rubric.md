# Visual Portfolio Rubric

| Dimension | Review question |
|---|---|
| Context | Is the visual/cultural situation specific? |
| Question | Can the reviewer name what was unknown? |
| Evidence | Are methods, traces, and sources credible? |
| Insight | Is there a turn in understanding? |
| Position | Does the student make a defensible choice? |
| Translation | Can we see how research changed visual form? |
| Experiment | Are alternatives and learning visible? |
| System | Do rules work across new content and medium? |
| Craft | Does production support the argument? |
| Narrative | Does pacing guide attention and causality? |
| Authorship | Is the student's judgment visible? |
| Reflection | Are limits, ethics, and future questions honest? |

## Readiness test

In 60 seconds, a reviewer knows the tension and outcome. In 5 minutes, they understand the evidence chain. In 15 minutes, they see authorship, iteration, craft, and unresolved intelligence.
