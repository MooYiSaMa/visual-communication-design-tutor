# Design Research Framework

## Research is a decision system

For every method or source, complete:

```text
unknown → method/source → evidence → interpretation → insight
→ design decision → test → learning
```

If no design decision can be named, the activity is context gathering, not yet research that drives design.

## Evidence hierarchy by question

| Question type | Strong evidence | Weak substitute |
|---|---|---|
| what people do | observation, artifact walkthrough | opinion poll only |
| why a workaround exists | contextual interview + trace | designer assumption |
| how a visual context is structured | contextual interviews + relationship map | designer assumption |
| whether a form communicates | task test + observation | designer taste |
| what precedents demonstrate | primary case/source analysis | uncredited moodboard |

Use triangulation when a claim affects a central design decision. Note whose view is missing.

## Synthesis protocol

```text
raw trace → descriptive code → cluster → contradiction → insight
```

Code behavior, triggers, constraints, workarounds, emotions, language, power, and absences. Keep quotes and interpretations visibly separate.

## Context and relationship map

Map people, institutions, objects, media, and cultural forces by relationship, influence, dependency, friction, and responsibility. Include voices that are absent from the dominant visual narrative.

## Reference taxonomy

| Type | Use it to learn | Do not use it as |
|---|---|---|
| method | how a project investigated | proof that your context is identical |
| context | historical/social framing | decorative citation |
| precedent | an existing solution/system | permission to copy |
| visual language | formal mechanisms | style to imitate |
| material process | affordance and constraint | a shortcut to meaning |
| audience/sector evidence | expectations and conditions | universal truth |

Log author, date, URL/archive, claim, relevance, transferable principle, and boundary. Distinguish direct observation from desk research.

## Ethics

Obtain informed consent where needed, minimize identifying information, let participants withdraw, avoid extracting trauma for aesthetic effect, and do not claim representativeness from a tiny sample. Make uncertainty visible.
