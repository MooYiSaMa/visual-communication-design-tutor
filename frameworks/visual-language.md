# Visual Language Framework

## Translate meaning into a system

Use the chain:

```text
position → intended audience experience → visual principle
→ formal rule → variation/state → test
```

A visual language is a set of repeatable relationships, not a collection of effects.

## Formal device prompts

| Meaning/behavior | Devices to test |
|---|---|
| partial access | crop, occlusion, threshold, delayed reveal |
| repetition with change | sequence, iteration, variable type/image |
| conflicting voices | overlap, competing hierarchy, split channels |
| institutional pressure | formality, grids, constraints, redaction, scale |
| uncertainty | conditional states, gaps, ambiguity, branching |
| collective contribution | modular units, aggregation, annotation, recomposition |

Choose devices because they model a behavior or relationship. Do not treat this table as a one-to-one metaphor dictionary.

## System dimensions

Specify typography, image, color, composition, material, motion, content, and medium together. Test the language with new content and an edge case; if it works only on a hero image, it is not a system yet.

## Audience experience

Describe what the audience notices first, does next, understands later, and may misunderstand. Design the sequence of attention, not only the surface.
