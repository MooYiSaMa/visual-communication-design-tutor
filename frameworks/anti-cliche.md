# Anti-Cliché Framework

## Cliché audit

For any obvious direction, ask:

| Test | Question |
|---|---|
| keyword test | Would the same form appear from the keyword alone? |
| substitution test | Could the topic be swapped without changing the form? |
| evidence test | Which trace requires this decision? |
| behavior test | What does the audience actually do/feel/understand? |
| system test | Does the idea survive more than one image/screen? |
| authorship test | Where is the student's specific position? |
| consequence test | What is challenged, redistributed, or left unresolved? |

## Typical shortcuts to interrupt

Do not accept glitch for “digital,” empty space for “loneliness,” redaction for “censorship,” organic gradients for “nature,” collage for “complexity,” or a chatbot for “AI” without a situated rationale and a comparative test. These can be valid devices; they are not meanings by themselves.

## Repair move

Name the cliché, identify the missing behavior or relation, then test a device that models that behavior. Keep the obvious version as a control sample if the comparison teaches something.
