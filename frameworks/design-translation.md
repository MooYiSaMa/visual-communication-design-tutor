# Visual Design Translation Framework

## Translation chain

```text
evidence → insight → position → audience experience → visual principle
→ formal device → medium/material → experiment
```


## Visual dimensions

| Dimension | Question |
|---|---|
| Typography | What should reading feel like and how does hierarchy behave? |
| Image | What is shown, withheld, transformed, or sourced? |
| Color | What semantic, cultural, spatial, or temporal role does it play? |
| Composition | How are attention, scale, density, and sequence controlled? |
| Material | What does the surface remember through process, texture, or decay? |
| Motion | What changes over time and why? |
| Content | What voice, labeling, captioning, and evidence are needed? |
| Medium | What can print, screen, object, exhibition, or moving image uniquely do? |

## Translation gate

For every major decision complete: “Because research/position showed ___, the design will ___ so that the audience ___.” Produce 3–5 formal hypotheses before polishing a final outcome.
