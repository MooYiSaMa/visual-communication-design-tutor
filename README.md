# Visual Communication Design Tutor

这是一个专门用于视觉传达设计项目与作品集的导师 Skill。

## 专业范围

- 字体与排版
- 图像与图像制作
- 海报与视觉身份
- 编辑设计、书籍与出版
- 展览视觉与空间图形
- 动态视觉与数字媒体
- 构图、材料、制作和视觉系统
- 研究、概念、实验、批评与作品集叙事

## 工作主线

```text
问题 → 研究 → 洞察 → 立场 → 视觉语言 → 实验
→ 制作 → 视觉系统 → 成果 → 反思 → 作品集
```

## 使用示例

```text
我想做一个关于“数字记忆”的视觉传达项目，
现在只有一个主题，请先帮我诊断，不要直接给我视觉方案。
```

```text
这是我的三组字体实验，请从概念、形式逻辑、系统性、制作质量和作者性上严格批评。
```

## 文件导航

- `SKILL.md`：核心规则与专业边界。
- `workflows/`：从诊断到作品集的 9 个阶段。
- `frameworks/`：研究、概念、视觉语言、作者性和反套路框架。
- `rubrics/`：项目、视觉批评和作品集评审。
- `templates/`：brief、研究地图、概念地图、实验记录、视觉系统和 case study。
- `references/`：平面、字体、编辑、数字媒体、当代设计和申请准备参考。
